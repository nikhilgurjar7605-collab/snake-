# PIXORA

**Play more. Live the game.** A mobile-first browser arcade portal.

## Stack
- React + TypeScript
- Vite
- Lucide icons
- CSS-driven visual system and startup animation

## Current scope
- Responsive homepage and mobile navigation
- Search and category filtering
- Game detail / preview pages
- Device-local favorites
- Honest empty Trending state until real play analytics exist
- Eight game slots clearly marked Coming Soon
- No forced sign-in and no playable-game claims yet

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

Game implementation, play-event analytics, score persistence and accounts are intentionally deferred.
